# Gaussi

Gaussi is a two-part interface for Gaussian splat workflows:

1. Navigate `.ply` Gaussian splat scenes generated by OpenSplat.
2. Upload videos and convert them into `.ply` scenes with FFmpeg, COLMAP, and OpenSplat.

The frontend is a Vite/React app intended for Vercel. The backend is a FastAPI service intended for a GCP VM where COLMAP and OpenSplat are installed.

## Project Layout

```text
frontend/   Vercel app: viewer, scene library, uploads, job polling
backend/    GCP VM API: artifact storage, conversion queue, static scene serving
```

## Environment

Frontend:

```bash
VITE_API_BASE_URL=https://api.example.com
```

Backend:

```bash
GAUSSI_DATA_DIR=/var/lib/gaussi
GAUSSI_PUBLIC_BASE_URL=https://api.example.com
GAUSSI_FRONTEND_ORIGINS=https://your-vercel-app.vercel.app
GAUSSI_COLMAP_BIN=/usr/local/bin/colmap
GAUSSI_OPENSLAT_BIN=/usr/local/bin/opensplat
```

The backend command templates are env vars too, so the VM can use the exact COLMAP global mapper and OpenSplat CLI syntax installed there without code changes.
